# Security Policy

## Supported versions

BeautifulUI has no tagged release yet. Security fixes go to `main`.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/szupzj18/BeautifulUI/security) of this repository and choose
**Report a vulnerability**. Include what you found, the component and the steps to reproduce it.

You will get an answer as soon as the maintainer can read the report. A confirmed issue is fixed
on `main` first and disclosed in the changelog once a fix is available.
